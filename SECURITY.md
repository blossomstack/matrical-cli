# Security

Report a flaw privately through [GitHub's private vulnerability reporting](https://github.com/blossomstack/matrical-cli/security/advisories/new), not in a public issue. Say what you found and how to reproduce it.

Only the latest release is supported.

Everything published to Matrical stays in storage for the plan's history window (7 days on the free plan, 30 on the paid one), including removed items and text an update replaced. Never publish secrets, passwords or keys; if one is published by mistake, change the secret itself.
